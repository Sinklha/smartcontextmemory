# ORIGINAL PLAN — Smart Context Memory (SCM Pro), исходная версия
# Сохранено как точка отсчета. Приоритеты для серверного софта (от автора):
# 1. zlib + переход в RAM | 2. графы и паспорта | 3. вспышка |
# 4. Asynchronous Flash Engine & Event Cleanup

Проект **Smart Context Memory (SCM Pro)** — это гибридная система управления контекстом для оптимизации работы локальных LLM (Large Language Models) при анализе больших кодовых баз и технической документации.
Система решает ключевую проблему современных нейросетей — **переполнение видеопамяти (VRAM)** и падение скорости генерации при работе с длинными контекстами.

---

### Архитектура и ключевые модули

Система построена по принципу двухуровневого хранения (RAM/VRAM) с динамической подгрузкой контекста по запросу.

**Модуль 1: Cross-Modal Semantic Router**

* Принимает входные данные и в реальном времени разделяет их на две категории: исходный код и текстовую документацию.
* Генерирует сквозной `Cross-Hash ID` (SHA-256), связывающий код и описание в единый контекстный узел.

**Модуль 2: Hybrid Compression Engine**

* Сжимает блоки кода алгоритмом `zlib` без потерь в оперативной памяти (RAM).
* Сохраняет структуру кода, сокращая занимаемый объем в системной памяти до 70–80%.

**Модуль 3: GraphRAG & Passport System**

* Текстовая документация индексируется в векторной базе данных FAISS с привязкой `Cross-Hash ID` к метаданным векторов.
* Для каждого блока формируется легкий паспорт (metadata-passport) с указанием размера, типа данных и текущего местоположения (RAM/VRAM).

**Модуль 4: Asynchronous Flash Engine & Event Cleanup**

* **Predictive Pre-fetching:** При совпадении запроса в FAISS система фоново (по шине PCIe) подгружает и разжимает нужный блок кода из RAM во VRAM до того, как модель начнет генерацию.
* **Event-Driven Cleanup:** В момент получения специального токена завершения ответа `[EOS]` (End of Sequence) блок кода немедленно стирается из VRAM, возвращая видеокарту в состояние покоя.

### Стек технологий

* **Язык разработки:** Python 3.13
* **Векторный поиск & Эмбеддинги:** FAISS, LangChain, HuggingFace (`all-MiniLM-L6-v2`)
* **Сжатие данных:** `zlib`, `hashlib`
* **Асинхронность:** `asyncio`

---

### Метрики эффективности (ЗАЯВЛЕННЫЕ, НЕ ЗАМЕРЕННЫЕ — см. разбор)

| Показатель | Традиционный подход | SCM Pro |
| --- | --- | --- |
| **Загрузка VRAM в покое** | 100% объема контекста | ~0% (только паспорта и векторы) |
| **Потребление RAM** | Исходный размер | На 50–70% меньше (zlib-сжатие) |
| **Защита от OOM (Out of Memory)** | Нет (вылет при лимите) | Да (динамическая выгрузка по [EOS]) |
